# Analog Clock

A live analog clock built with CSS and JavaScript, showing the time, date, and day of the week.


## Features

- Hour, minute, and second hands (gold second hand)
- 60 dial markings around the face, with numbered 12 / 3 / 6 / 9 positions
- Date display (DD/MM/YYYY) and day of the week
- Updates every 100 ms, so the second hand moves smoothly

## Tech Stack

- HTML
- CSS
- JavaScript (single self-contained file)

## How to Run

Just open `index.html` in any browser. No build step, no server needed.

```bash
# or serve it locally
python3 -m http.server
# then open http://localhost:8000
```
